## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Gokul-Dev2004/kaizen-js.git
```

### 2. Navigate to the project folder

```bash
cd kaizen-js
```

### 3. Open the project

Open `index.html` in your browser to run the project locally.
